# CS190-Final-Project
This project is built in order to keep track with my playlist. It is designed to manage changes in the playlist, including add, delete, creating and using a backup playlist. 

MVP Scope:
1. Setup github repository and java project
2. Create Song class and Playlist class
3. Write Basic methods needed
4. Write playlist comparison
5. Connect with Spotify using Spotify API
6. Test the project and finalize.

Future Plans: 
1. Integrate with Spotify using the Spotify Web API.
2. Display the difference between the two playlist.
3. Being able to undo accidental changes
